# Beginner Safety Checklist

อ่าน checklist นี้ก่อนพัฒนา อัปเดต หรือดูแลระบบ BrakeCheck

## ก่อนยุ่งกับฐานข้อมูล

- อย่าแก้ฐานข้อมูลจริงมั่ว ๆ
- อย่าใช้ฐานข้อมูลจริงเป็นที่ทดลอง
- ก่อนยุ่งกับฐานข้อมูลจริง ต้อง Backup ก่อนเสมอ
- ถ้าไม่แน่ใจว่าเป็นฐานข้อมูลจริงหรือทดสอบ ให้หยุดและถามก่อน

## คำอันตราย

ถ้าเห็นคำเหล่านี้ ให้หยุดคิดก่อนรัน:

- `DROP`
- `TRUNCATE`
- `RESET DATABASE`
- `DELETE ALL`
- `DELETE FROM` แบบไม่มีเงื่อนไขชัดเจน

คำเหล่านี้อาจทำให้ข้อมูล QC หายได้

## ห้ามใส่ความลับลง GitHub

- อย่าใส่รหัสผ่านลง GitHub
- ห้าม commit `.env`
- ห้าม commit `*.sql` ที่เป็น backup หรือ dump ข้อมูลจริง
- ห้าม commit โฟลเดอร์ `backups/`
- ห้าม commit token, database password, หรือข้อมูลโรงงานจริง

## อย่าให้เพิ่มของใหม่โดยไม่จำเป็น

ห้ามให้ Codex เพิ่มสิ่งเหล่านี้ถ้ายังไม่ได้อนุมัติ:

- Docker
- TypeScript
- Tailwind CSS
- Next.js
- Prisma
- Sequelize
- Cloud database
- Paid service
- frontend/backend framework ใหม่

ใช้ HTML, CSS, JavaScript, Node.js, Express และ PostgreSQL 17 ตามระบบปัจจุบัน

## ก่อนอัปเดตระบบ

- อย่าอัปเดตระบบโดยไม่ทดสอบ
- ตรวจ `git status` ก่อน
- อ่าน requirement ให้ครบ
- Backup database ถ้ามี migration หรือกระทบข้อมูล
- ตรวจว่าไม่ได้ใช้ฐานข้อมูลจริงเป็นที่ทดลอง
- แก้ทีละเรื่อง อย่าแก้หลายเรื่องพร้อมกัน

## หลังแก้ระบบ

- อย่าเชื่อว่ารันผ่านแปลว่าใช้งานจริงได้
- ต้อง test workflow ที่ผู้ใช้ใช้งานจริง
- ต้องเช็ก API health
- ต้องเช็ก database health
- ต้องจดว่าแก้อะไรไป
- ต้องจดว่า test อะไรไปแล้ว
- ต้องบอกสิ่งที่ยังไม่ได้ test

## ระหว่างใช้งานจริง

- อย่าปิดเครื่องแม่ถ้ามีคนใช้งานระบบอยู่
- อย่าปิด PostgreSQL ถ้ามีคนกำลังบันทึกงาน
- อย่าปิด server ถ้ายังไม่ได้แจ้งผู้ใช้
- ถ้าจะอัปเดตระบบ ให้เลือกเวลาที่ไม่มีคนใช้งาน

## ประโยคที่ควรใช้กับ Codex บ่อย ๆ

- ใช้ `beginner-safe-coding` ก่อนเริ่มงานนี้
- อ่านเฉพาะไฟล์ที่จำเป็นก่อน
- ก่อนแก้ไฟล์ ให้บอกว่าจะยุ่งกับไฟล์ไหน
- ห้ามแก้ logic ระบบจนกว่าฉันจะอนุมัติ
- ห้ามแก้ฐานข้อมูลจริง
- ถ้าต้องรัน migration ให้ถามก่อน
- ถ้าไม่แน่ใจว่าเป็นฐานข้อมูลจริงหรือทดสอบ ให้หยุดถามก่อน
- หลังแก้เสร็จ สรุปไฟล์ที่เปลี่ยนและสิ่งที่ทดสอบ
- ยังไม่ต้อง `git add/commit` จนกว่าฉันจะสั่ง
