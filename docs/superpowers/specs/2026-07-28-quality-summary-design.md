# Quality Summary Design

วันที่: 2026-07-28

## เป้าหมาย

เพิ่มหน้า `Summary` สำหรับดูภาพรวมผลคุณภาพและแนวโน้มในระบบ โดยไม่ซ้ำกับ Dashboard ซึ่งใช้ติดตามคิวงานประจำวัน

หน้านี้เป็นรายงานสดจากสถานะล่าสุด ไม่ใช่รายงานปิดยอด หากข้อมูลได้รับการแก้ไขอย่างถูกต้อง ผลสรุปย้อนหลังจะคำนวณใหม่ตามข้อมูลล่าสุด

## ขอบเขต

- เพิ่มเมนู `Summary` ในกลุ่ม `รายงาน`
- เข้าได้เฉพาะ `head` และ `assistant`
- ใช้วันที่ผลิตจาก Excel Column T เป็นวันที่หลัก
- แสดงตัวเลขสรุปและตาราง โดยไม่ใช้กราฟ
- ไม่เพิ่ม dependency หรือบริการภายนอก
- ดูข้อมูลในระบบเท่านั้น ไม่มี Export
- ไม่แสดงสถิติหรือการจัดอันดับรายบุคคล
- หน้า Summary อ่านอย่างเดียว ไม่มีคำสั่งแก้ไข อนุมัติ หรือรับทราบ NG

## ตัวกรอง

- ช่วงวันที่ผลิต สูงสุด 12 เดือนต่อครั้ง
- รุ่น/รายละเอียด
- เกรด
- ปุ่มรีเฟรช
- เวลาอัปเดตล่าสุด

ค่าเริ่มต้นเป็นเดือนปัจจุบัน ตัวกรองทุกตัวต้องใช้ร่วมกันกับตัวเลขและตารางทั้งหมด

## ตัวเลขสรุป

แสดง 5 ค่า:

1. Lot ที่มีผลคุณภาพสุดท้าย
2. Approved
3. รับทราบ NG
4. อัตรา NG ต่อ Lot
5. งานที่ยังไม่จบ

สูตรอัตรา NG:

```text
จำนวน Lot ที่รับทราบ NG
------------------------- x 100
จำนวน Lot ที่มีผลคุณภาพสุดท้าย
```

ยังไม่มีเป้าหมายอัตรา NG ที่บริษัทอนุมัติ จึงแสดงเฉพาะตัวเลขโดยไม่ใช้สีตัดสินว่าดีหรือไม่ดี

## กฎสถานะ

ผลคุณภาพสุดท้ายประกอบด้วย:

- Approved
- รับทราบ NG

งานที่ยังไม่จบแยกเป็น:

- รอตรวจ
- กำลังตรวจ
- รอแก้ไข
- รอตรวจบรรจุ
- รออนุมัติ

งาน Void ไม่นับรวมในผลคุณภาพสุดท้ายและงานที่ยังไม่จบ

## ตารางแนวโน้มผลคุณภาพ

คอลัมน์:

- ช่วงเวลา
- Lot ที่จบทั้งหมด
- Approved
- รับทราบ NG
- อัตรา NG

การจัดกลุ่ม:

- เดือนปัจจุบัน: รายวัน
- ย้อนหลัง 3 เดือน: รายสัปดาห์
- ย้อนหลัง 12 เดือน: รายเดือน
- สัปดาห์เริ่มวันจันทร์และสิ้นสุดวันอาทิตย์

## ตารางหัวข้อที่พบ NG สูงสุด

- แสดง 5 อันดับและแถว `อื่น ๆ`
- เลือกดู `ทั้งหมด`, `ตรวจมิติ` หรือ `ตรวจบรรจุ`
- แสดงชื่อหัวข้อ แหล่งที่มา และจำนวน Lot NG
- หนึ่ง Lot นับไม่เกินหนึ่งครั้งต่อหนึ่งหัวข้อ

## ตารางรุ่นที่พบ NG สูงสุด

- แสดง 5 อันดับและแถว `อื่น ๆ`
- เรียงตามอัตรา NG ต่อ Lot
- แสดงจำนวนในรูปแบบ เช่น `5/10 Lot (50%)`
- รุ่นที่มีผลคุณภาพสุดท้ายน้อยกว่า 5 Lot แสดงป้าย `ข้อมูลน้อย`

## ตารางเปรียบเทียบรายปี

- เปรียบเทียบได้ครั้งละ 1-3 ปี
- ค่าเริ่มต้นเป็นปีปัจจุบันและย้อนหลัง 2 ปี
- ผู้ใช้เลือกปีอื่นที่มีข้อมูลได้
- ปีหนึ่งนับตั้งแต่ 1 มกราคมถึง 31 ธันวาคม
- ใช้ตัวกรองรุ่นและเกรดร่วมกัน

คอลัมน์:

- ปี
- Lot ที่จบทั้งหมด
- Approved
- รับทราบ NG
- อัตรา NG
- อัตรา NG เพิ่มหรือลดจากปีก่อน

## รายการ Lot แบบเจาะรายละเอียด

เมื่อกดตัวเลขสรุปหรือแถวในตาราง ให้แสดงรายการ Lot ที่ตรงกับเงื่อนไขด้านล่างหน้า

คอลัมน์:

- Lot
- วันที่ผลิต
- รุ่น/รายละเอียด
- เกรด
- ผลคุณภาพสุดท้าย
- หัวข้อ NG
- ปุ่ม `ดูข้อมูล`

รายการต้องแบ่งหน้า ปุ่ม `ดูข้อมูล` เปิดรายละเอียดเดิมในโหมดอ่านอย่างเดียว

## Backend และข้อมูล

- คำนวณจากสถานะล่าสุดของแต่ละ Lot
- ใช้ PostgreSQL query แบบ parameterized
- ตรวจรูปแบบวันที่ ปี รุ่น เกรด ประเภทตาราง และขอบเขต 12 เดือนที่ Backend
- จำกัดสิทธิ์ทุก Summary API ให้เฉพาะ `head` และ `assistant`
- Query สรุปต้องคืนเฉพาะข้อมูลที่หน้าจอจำเป็นต้องใช้
- ไม่คืนชื่อผู้ตรวจ รหัสผ่าน session token หรือข้อมูลภายในระบบ
- ไม่ต้องแก้ Schema หากข้อมูลปัจจุบันรองรับการคำนวณครบ

## สถานะหน้าจอ

- Loading: ปิดการกดซ้ำและแสดงว่ากำลังโหลด
- Empty: แจ้งว่าไม่พบข้อมูลตามเงื่อนไข
- Error: แสดงข้อความทั่วไปโดยไม่เปิดเผย SQL หรือ stack trace
- Unauthorized: ผู้ไม่ Login ได้ `401`
- Forbidden: Role ที่ไม่มีสิทธิ์ได้ `403`

## การทดสอบที่จำเป็น

- สูตร Approved, NG, อัตรา NG และงานค้างตรงกับข้อมูลทดสอบ
- ไม่รวม Void และงานที่ยังไม่จบในตัวหารอัตรา NG
- ตัวกรองวันที่ รุ่น และเกรดใช้ตรงกันทุกส่วน
- จัดกลุ่มวัน สัปดาห์ เดือน และปีถูกต้อง
- เปรียบเทียบได้ไม่เกิน 3 ปี
- นับหัวข้อ NG แบบ distinct Lot
- แสดงป้าย `ข้อมูลน้อย` ถูกต้อง
- Drill-down แสดง Lot ตรงกับตัวเลขที่กด
- `head` และ `assistant` เข้าได้ แต่ `officer` ได้ `403`
- Loading, Empty, Error และ pagination ทำงาน
- ตรวจหน้าจอ Desktop, Tablet และ Mobile

## สิ่งที่ไม่ทำในงานนี้

- กราฟ
- Chart.js หรือ dependency ใหม่
- Export PDF/Excel
- เป้าหมายหรือสีตัดสินอัตรา NG
- สถิติรายบุคคล
- Snapshot ปิดยอดรายเดือนหรือรายปี
- การแก้ไขข้อมูลจากหน้า Summary
